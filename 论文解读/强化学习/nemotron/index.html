03 · NEMOTRON-4

第一代核心：用大模型生产数据，再用奖励模型筛选数据

Base4.5T token预训练340B
Synthetic prompts任务分类+生成指令
Multi responses生成多个候选答案
Reward filteringHelpSteer2多属性RM排序
AlignmentSFT / SteerLM / DPO / PPO

贡献

Nemotron-4把“强模型—合成数据—奖励模型—学生/对齐模型”形成闭环。340B Reward能够预测helpfulness、correctness、coherence、complexity、verbosity等属性；Instruct模型的质量很大程度来自数据策展和奖励过滤，而非基座架构变化。

传承关系：后来的Llama-3.1-Nemotron-70B-Instruct和Reward沿用这一数据/奖励路线，并成为Llama-Nemotron生成与拒绝采样的重要教师。
04 · LLAMA-NEMOTRON

五阶段构建：模型先变快，再恢复能力，最后学会长推理

1 NAS从Llama 3搜索高效子结构
2 FFN Fusion合并相邻FFN以提高吞吐
3 Recovery知识蒸馏+CPT恢复精度
4 SFT + RL数学、代码、科学、工具调用
5 Alignment指令遵循与人类偏好

Reasoning Toggle

训练集对同一prompt构造reasoning-on与reasoning-off响应，让一个模型在推理时通过指令切换“快速回答”和“深度思考”，而不必部署两套模型。

关键理解：Llama-Nemotron不是从零预训练的新架构，而是对Llama 3系列进行结构搜索、恢复训练和推理专项后训练所得的异构模型族。
05 · HYBRID ARCHITECTURE

Nemotron-H与Nano 2：为什么要用Mamba替代大多数Attention？

长思维链解码中，Attention每步都要访问增长的KV Cache；Mamba-2以固定状态递推，可显著降低生成阶段的内存流量。Nemotron-H保留少量Attention以维持检索和上下文能力，其余层使用Mamba-2，并穿插FFN。

Nemotron-H验证混合层配比与8B、56B/47B规模；核心目标是accuracy—throughput Pareto。
Nano 2 Base12B模型在20T tokens上采用FP8预训练，先获得足够强的教师。
Minitron通过深度/宽度等结构剪枝与知识蒸馏得到9B学生，不是简单量化12B。
容易混淆：Llama-Nemotron Nano 8B来自Llama结构搜索；Nemotron Nano 2 9B来自Nemotron-H式混合架构，两者不是同一模型的小版本升级。
06 · NEMOTRON 3 / 3.5

Nano、Super、Ultra与最新Lightning如何分工

模型规模定位/预训练核心架构与系统技术上下文
Nano30B总 / 3B激活25T tokensMamba-Transformer MoE；多环境RL1M
Super120B总 / 12B激活NVFP4 recipeLatentMoE；NVFP4；MTP1M
Ultra550B总 / 55B激活20T text tokens大规模Hybrid Mamba-Attention MoE1M
3.5 Lightning30B总 / 3B激活常驻Agent快速专项执行Mamba-2+MoE+少量Attention；MTP；DFlash/DSpark；NVFP41M

Nemotron 3.5 Lightning：不是Ultra的缩小版

它于2026年8月11日开放，直接继承Nano级30B-A3B计算档位，目标是代码审查、安全监控和长时间运行Agent等高频专项任务。NVIDIA开放BF16与NVFP4权重、训练数据和配方，采用OpenMDW-1.1许可。

混合结构30B总参数、约3B激活，交错Mamba-2与MoE层，仅保留部分Attention。
多路投机解码除原生MTP外还发布DFlash和DSpark路径，模型与解码系统协同优化。
单卡部署官方提供单H100运行NVFP4的vLLM配方，同时给出SGLang使用路径。
证据边界：目前主要依据是官方模型卡、训练配方和发布说明，尚未检索到独立的3.5 Lightning arXiv技术报告；因此发布宣称的最高4×生成速度和30%更短完成时间不能视为跨环境普适结论。

三项真正的代际变化

Hybrid MoEMoE减少每token激活计算，Mamba减少Attention/KV成本，两者共同优化长输出吞吐。
Multi-environment RL不只在数学答案上做RL，而是在推理、代码、工具调用和交互环境中联合后训练。
系统协同设计从Super/Ultra的NVFP4+MTP，发展到Lightning同时发布多种投机解码路径。

08 · EVOLUTION

技术演进不是简单“参数越做越大”

数据人工偏好与合成数据 → 完整推理后训练集 → 开放预训练/RL blend。
架构Dense Transformer → NAS异构Llama → Mamba-Transformer → Hybrid MoE + LatentMoE。
训练SFT/SteerLM/DPO/PPO → 蒸馏+大规模RL → 多环境RL与级联RL。
精度BF16为主 → FP8预训练 → Super开始NVFP4预训练。
解码普通自回归 → 长思维链吞吐优化 → MTP原生投机解码。
产品形态Chat/Reward Model → Reasoning Toggle → 长上下文Agent与Omni感知。
09 · READING ORDER

推荐阅读顺序

  1. Nemotron-4 340B：先理解NVIDIA的数据生成、奖励模型和对齐范式。
  2. Llama-Nemotron：理解NAS、蒸馏、SFT、大规模RL怎样组成推理模型流水线。
  3. Nemotron-H：理解混合Mamba-Transformer的层级结构和吞吐动机。
  4. Nemotron Nano 2：看FP8预训练、Minitron剪枝和蒸馏如何落地。
  5. Nemotron 3 White Paper → Nano → Super → Ultra：先看家族设计，再逐规模深入。
  6. 最后按兴趣读AceReason、CrossThink、Cascade、Tool-N1、Omni。
